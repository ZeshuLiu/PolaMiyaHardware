> 当前主控器 Rev 2.0 与对焦组件由 **KiCad 10** 保存，历史主控器、显示按键、电机驱动和闪光灯转接工程由 **KiCad 9** 保存。加工包和 BOM 位于相应模块的 `production/` 子目录中；使用前请核对兼容性表和输出快照。主控器 Rev 2.0 的投产验证资料为 `电路/主控器/PM_Controller/production/PM_Controller_2.0.zip` 及同目录 BOM、坐标、位号和网络表。

主控器后续更新在 `电路/主控器/PM_Controller/` 中进行，该工程已开始独立的 Rev 2.0 设计；`主要历史版本/PM_Controller_Rev1.3/` 保存冻结的旧版，并在其 `DispKey/` 子目录保存绑定的 Display Key Rev 1.0。历史 Display Key 不自动视为兼容新版主控器。每次重大版本归档应保存完整工程、绑定的配套 PCB、依赖库、加工资料和版本说明。

### PM_Controller Rev 2.0 状态与 Features

2026-10-06：PM_Controller Rev 2.0 已投产，机械装配已确认无问题，等待首件验证。当前全部待验证和待完善事项统一纳入 F01–F11，作为本轮投产验证的非阻断 feature 随首件验证、参数定型和固件适配推进；实测完成后更新对应 feature 状态。已投产不等同于量产验证已通过。

| Feature | 内容与验证目标 |
| --- | --- |
| F01 电机电流采样与限流调优 | 定型 C8/R12；IPROPI 就地小电容滤波与 ADC 大电容滤波分开配置，核对堵转峰值及限流响应。暂定 1 µF 与 R2=1 kΩ 对应约 1 ms 时间常数。 |
| F02 电池采样与关机低功耗 | 核对 U17 在 3.3 V 供电、满电电池约 4.2 V 输入及掉电过程中的允许范围；定型 C32，验证 GPIO3 储能泄放、隔离和关机电流。 |
| F03 吐片事件保持与冷启动 | 明确 U3 冷上电预置或软件初始化；主电源重启时保留真实事件，首次接入电池时完成初态处理。 |
| F04 电源动态调优 | 按实料的 DC 偏压降容、ESR 和分布位置核对输出电容；验证启动、轻载、无线发射叠加电机启停、制动回灌和电压恢复。 |
| F05 物料定型与生产版本管理 | 定型 C8/C32、L1 的 Isat/Irms/DCR、C7 耐压/浪涌/ESR、MLCC 有效容量、ESP32 存储容量后缀及 EEPROM 精确型号/脚序/容量；明确 FPC 二选一装配及 DNP，保持加工包、BOM 和坐标同一快照。 |
| F06 PowerPAD 装配工艺 | U5 EP 内 6 个 0.30 mm 散热孔与整块 2.41×3.10 mm 锡膏开窗配合，确认钢网锡量及封孔工艺，检查首件焊接和空洞。 |
| F07 电机与充电工作裕量 | 核对名义约 2.10 A 电机限流、最重吐片负载、堵转停机及 U5/U14/L2 温升；按最终充电芯片规格确认 RPROG=2.1 kΩ 的充电电流，验证 U2 实际电流与热降额。 |
| F08 USB 接口验证 | 验证正反插、枚举、传输与最终叠层阻抗；适配 U18 CT 浮空时 12–28 ms 插入延迟，验证满电轻载拔线后 GPIO21 在 3 ms 内变低。 |
| F09 ESP32 配套固件适配 | 核对 GPIO39=/PL、GPIO40=CLK、GPIO41=Q7，74HC165 D0–D7 为 KEY1–KEY6、CHG、STB，SPI 模式 2；实现锁存恢复、ADC 与电机保护，并明确 GPIO3/eFuse/JTAG 策略。现有 STM32 工程保留为历史固件。 |
| F10 闪光同步兼容范围 | 明确 H3.1 正极/H3.2 负极、目标闪光灯触发电流及工作限额；TLP291 的 VCEO=80 V、VECO=7 V、IC=50 mA 为绝对最大值，工作规格保留裕量；按需求扩展高压或无极性兼容。 |
| F11 工程表达与维护 | 完善导入符号电气类型、NC/PWR_FLAG、库型号及人工豁免说明，保持文档、物料和当前设计一致。 |

## 使用方法

### 相机操作
- **开机/关机**：长按机身左下角按钮 2 秒
- **吐片**：三向按钮长按中键 2 秒启动吐片电机，短按中键停止，随后推动侧面推杆吐出相纸
- **测距**：开机即运行

### 功能
- ✅ 电动吐片
- ✅ 电子测距
- 🔄 自动对焦（计划中）
- 🔄 测光（计划中）
- 🔄 全息取景器（计划中）
