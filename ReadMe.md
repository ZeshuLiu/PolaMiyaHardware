# PolaMiyaHardware - 宝丽来相机改装项目

宝丽来相机自动化改装项目的机械与电路设计部分。

> 完整项目：https://github.com/ZeshuLiu/PolaMiya
> 软件固件仓库：https://github.com/ZeshuLiu/PolaMiyaSoftware

### 电路设计

| 模块 | 说明 |
|------|------|
| [主控器：当前开发工程](电路/主控器/PM_Controller/) | Rev 2.0 开发中，STM32G030K8Tx + ESP32-S3-WROOM-1 |
| [主控器：Rev 1.3 历史归档](电路/主控器/主要历史版本/PM_Controller_Rev1.3/) | Rev2N 对应的冻结版本，与 DispKey Rev 1.0 绑定，见[版本说明](电路/主控器/主要历史版本/PM_Controller_Rev1.3/版本说明.md) |
| [DispKey：Rev 1.0 历史归档](电路/主控器/主要历史版本/PM_Controller_Rev1.3/DispKey/) | 与 PM_Controller Rev 1.3 绑定的屏幕与按键模块 |
| [电机驱动](电路/电机驱动/MotroDrive/) | 吐片电机驱动板 |
| [闪光灯转接](电路/闪光灯转接/FlashAdapter/) | 闪光灯转接板 |
| [对焦组件](电路/对焦组件/) | Rev3 对焦驱动板，PCB Rev 1.0 |

> 当前主控器 Rev 2.0 与对焦组件由 **KiCad 10** 保存，历史主控器、显示按键、电机驱动和闪光灯转接工程由 **KiCad 9** 保存。已有加工包和 BOM 位于相应模块的 `production/` 子目录中；加工包版本可能早于对应设计，使用前请核对兼容性表。主控器 Rev 2.0 尚处开发阶段，不以历史加工包作为其加工输出。

主控器后续更新在 `电路/主控器/PM_Controller/` 中进行，该工程已开始独立的 Rev 2.0 设计；`主要历史版本/PM_Controller_Rev1.3/` 保存冻结的旧版，并在其 `DispKey/` 子目录保存绑定的 Display Key Rev 1.0。历史 Display Key 不自动视为兼容新版主控器。每次重大版本归档应保存完整工程、绑定的配套 PCB、依赖库、加工资料和版本说明。

## 使用方法

### 相机操作
- **开机/关机**：长按机身左下角按钮 2 秒
- **吐片**：三向按钮长按中键 2 秒启动吐片电机，短按中键停止，随后推动侧面推杆吐出相纸
- **测距**：开机即运行

### 功能
- ✅ 电动吐片
- ✅ 电子测距
- 🔄 自动对焦（计划中）
- 🔄 测光（计划中）
- 🔄 全息取景器（计划中）
