# PolaMiyaHardware - 宝丽来相机改装项目

宝丽来相机自动化改装项目的机械与电路设计部分。

> 完整项目：https://github.com/ZeshuLiu/PolaMiya
> 软件固件仓库：https://github.com/ZeshuLiu/PolaMiyaSoftware

## 仓库结构

| 子目录 | 说明 |
|--------|------|
| [电路/](电路/) | KiCad 电路设计 |
| [结构 Rev2N/](结构 Rev2N/) | 机械结构 3D 模型 (STL/STP) |

### 电路设计

| 模块 | 说明 |
|------|------|
| [主控器](电路/主控器/PM_Controller_R1/) | 主控制器 (STM32G474) |
| [DispKey](电路/主控器/DispKey/) | 屏幕与按键模块 |
| [电机驱动](电路/电机驱动/MotroDrive/) | 吐片电机驱动板 |
| [闪光灯转接](电路/闪光灯转接/FlashAdapter/) | 闪光灯转接板 |

> 所有 PCB 使用 **KiCad 9** 绘制，Gerber 文件和 BOM 清单位于各模块的 `production/` 子目录中。

### 结构设计

| 组件 | 说明 |
|------|------|
| 镜头总成 | Mamiya Press 127mm 镜头安装座 |
| 片仓总成 | 宝丽来相纸仓 |
| 吐片机构 | 电动吐片下巴与齿轮组 |
| 外壳 | 相机主体外壳 |
| 全息取景器 | 计划中的升级部件 |

> 所有 STL 文件位于各组件的 `STL/` 子目录中，可用 A1 mini 或 Voron0 等小型 3D 打印机打印。

| 类别 | 工具/平台 |

主要采购件：
- Mamiya Press 127mm 镜头（不需要调焦桶）
- 宝丽来 AF5000（用于拆解吐片下巴、吐片电机和齿轮组）

## 使用方法

### 相机操作
- **开机/关机**：长按机身左下角按钮 2 秒
- **吐片**：三向按钮长按中键 2 秒启动吐片电机，短按中键停止，随后推动侧面推杆吐出相纸
- **测距**：开机即运行

### 功能
- ✅ 电动吐片
- ✅ 电子测距
- 🔄 自动对焦（计划中）
- 🔄 测光（计划中）
- 🔄 全息取景器（计划中）
